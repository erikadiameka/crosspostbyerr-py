# CrossPost-Py 🚀
> **Automated Multi-Platform Video Uploader** — Satu kali klik, sebar video testing ke berbagai platform media sosial secara bersamaan.

Proyek ini dibangun menggunakan **Python** untuk mengotomatisasi proses interaksi browser (via Playwright) dan integrasi API resmi guna mempermudah manajemen konten video short/reels di berbagai platform.

---

## 🛠️ Tech Stack & Fitur

### ⚡ Platform Terintegrasi:
* **TikTok** – Automation login & upload via *Playwright Stealth Engine* (Bypass detection).
* **YouTube Shorts** – Upload otomatis menggunakan *YouTube Data API v3*.
* **Facebook Pages** – Direct binary video upload melalui *Meta Graph API*.
* **Instagram Reels** – Automated media container & polling system menggunakan *Meta Graph API*.

### 🧰 Tools yang Digunakan:
* **Language:** Python 3
* **Automation:** Playwright (Chromium/Chrome Engine)
* **API Client:** Requests, Google API Client
